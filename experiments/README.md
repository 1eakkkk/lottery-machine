# 后续摇奖机器开发

线上玩法只有双色球和大乐透。此目录为尚未接入网站的开发模型，不将原型列入正式玩法入口。

## 福彩 3D

已开始三个独立十球球仓的完整物理出球原型，每仓标识为 0—9，顺序为百位、十位、个位；不同位置可以出现相同数字。当前复用已经验证的机械混合及单球隔离部件，待与用户提供的福彩节目逐帧对齐设备外观和实际混合方式。

运行：`npx tsx experiments/verify-fc3d.ts`。检查四个种子完整出球、位置顺序、零号处理、范围、异常边界和完整同输入物理状态复现。下一步为三机渲染、自动位置镜头、三个数字结果和手机布局；未接入正式 UI。

规则：[上海福彩 3D 规则](https://www.swlc.net.cn/games/3d.html)。

## 七乐彩

已开始同一球仓 30 球连续出 8 球的完整出球物理原型，开发种子 42 的范围、去重、接球槽与完整回放检查通过。前端尚未接入。前七个为基本号，最后一个为特别号，特别号仍从剩余球中产生。正式接收架外形与手机取景仍需验收，不把双色球蓝球仓当作特别号来源。

## 快乐 8

已开始 80 球仓连续抽 20 球的完整出球物理原型，使用内部无重叠装球排列与加长实体接球槽；开发种子 42 的范围、去重、槽内留球及完整回放检查通过。前端尚未接入，仍需独立校准球仓、装球密度与接收架外形。需要针对高密度碰撞、长时间混合及手机渲染单独验收，不能仅替换 UI 号码数量。

运行原型检查：`npx tsx experiments/verify-single-pool.ts qlc` 和 `npx tsx experiments/verify-single-pool.ts kl8`。单一种子通过仅说明当前原型可运行，不能替代正式上线的多种子稳定性和手机 UI 验收。

规则：[上海福彩七乐彩规则](https://www.swlc.net.cn/games/qlc.html)，[四川福彩快乐 8 规则](https://www.scflcp.com.cn/yxgz/822062773.jhtml)。
