# 大乐透开发实验

状态：已开始气流搅拌原型，未上线大乐透开奖，尚未实现捕球阀和完整出球。

规则为前区 01—35 抽取 5 个、后区 01—12 抽取 2 个，同区不放回。采用独立模型，不复用双色球双转盘搅拌。

`dlt-airflow.ts` 已实现真实 Rapier 球体、闭合球仓碰撞、等质量泡沫球的近似参数、空间气流场和相对风速的阻力作用。风场对所有球采用同一规则，编号不参与施力；初始身份排列按种子打乱。模型使用开发尺度和经验流场，并非真实设备标定或完整流体动力学计算。

运行原型检查：`npx tsx experiments/verify-dlt-airflow.ts`。检查前后区各三个种子、十秒混合过程、球体越界、上升混合和相同输入状态复现。这个检查不代表完整大乐透开奖已经通过验收。

下一步：确认维纳斯捕球通道与阀门的视觉参考，加入单球隔离与不放回检测，完成 5＋2 物理流程；随后接入独立的球仓、机箱、镜头与移动端玩法选择，进行批量完整开奖验证后再合并上线。
