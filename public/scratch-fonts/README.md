# 本地印刷字体子集

- ticket-numbers.ttf：Google Fonts Roboto Condensed，700，数字、¥、标点及大写拼音子集。
- ticket-symbols.ttf：Google Fonts Noto Sans SC，900，喜／囍等字及数字子集。
- 原项目与 OFL 授权：https://github.com/google/fonts/tree/main/ofl/robotocondensed ，https://github.com/google/fonts/tree/main/ofl/notosanssc 。同目录保留各自完整 OFL 文本。

字体随站点部署，不在运行时请求外部字体服务。用于接近公开实物的印刷风格，不是发行机构专用字模。
