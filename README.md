# 一刻开奖

支持双色球、大乐透、福彩 3D、七乐彩、快乐 8 的三维开奖模拟网站。Rapier 3D WASM 计算球体和机器的真实碰撞；双色球使用双向机械转盘，大乐透使用经验气流阻力场，分别带动球体混合。Three.js 显示透明球仓、机构和实际建模的出球通道。

- 已上线：https://lottery.1eak.cool
- 公开仓库：https://github.com/1eakkkk/lottery-machine
- 完整产品与实施方案：[PROJECT_PLAN.md](PROJECT_PLAN.md)

## 功能

双色球：33 个红球中逐个抽取 6 个，再从 16 个蓝球中抽取 1 个。大乐透：35 个前区球中抽取 5 个，再从 12 个后区球中抽取 2 个。五个玩法使用独立模型版本和历史记录。福彩 3D 使用三个 0—9 独立球仓，按百十个位显示（保留前导零、允许跨仓重复、不能升序）。七乐彩在同一 30 球仓中连续抽取七个基本号码和一个特别号码。快乐 8 在同一 80 球仓中抽取二十个不同号码。支持电脑和手机、镜头切换、暂停继续、重新开始、开奖音乐与音效、结果复制、升序显示、账户历史记录及种子回放。

每位访客在本机独立模拟，无需登录。登录采用邮箱与密码，验证邮箱后才能保存和查看自己的跨设备记录；退出后隐藏记录。旧本机记录保留，可在登录后主动导入。账户后台使用 Cloudflare Workers 与独立 D1 数据库，邮件通过 Resend 发送，配置见 [账户部署说明](docs/ACCOUNTS.md)。号码由球通过实际建模的出口产生，没有预先确定开奖号码的代码。初始球位按种子打乱，球号不决定质量、摩擦或运动规则。

球面号码使用固定曲面贴印，会随球体转动并被遮挡；球体材质与重复圆标参考福彩公开球组照片。点击开奖后播放原创合成音乐，完成后播放结束短奏与柔和结果音乐。声音开关统一控制，暂停与后台同时静音。复制结果不包含种子。

6 和 9 的球面圆标增加随球旋转的下划线。大乐透、福彩 3D 的气流模型升级为 v2：扩大上升气流的覆盖，增加上部外扩和底部回流，去除按球色降低风速的设置；可见中央散流口与气流场对应。账户中已有的旧 v1 记录仍可查看号码，但不以新模型误回放。

开奖过程中，球沿原出口落到倾斜单行接球槽，依靠重力和真实碰撞滚至末端、按出球先后逐个靠拢。可使用接球架镜头观察，球体不会在过程中被转移到独立展示架。全部开奖结束后才整理到独立展示架并开放结果特写。桌面支持指向鼠标位置的滚轮缩放、右键平移和双击放大；移动按钮可以切换拖动模式。手机三维区域支持双指缩放/平移、双击放大，操作范围限制在三维区域内。

## 本地运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm test` 检查完整出球、不放回、号码范围、先红后蓝及相同输入的状态复现。通过 `DRAW_TEST_COUNT` 可以扩大种子数量。物理测试具有实际运算量，不是预生成结果的单元测试。

`npm run test:airflow` 检查 10、12、35 球仓各四个种子的持续混合，测量上半仓占比、上部到达率和高度分位数，并验证球色不改变受力和球体不越界。该检查用于发现气流过浅或聚集，不构成设备标定或随机公平性证明。

## 发布

使用 Cloudflare Workers Static Assets；构建输出为 `dist/`，配置见 `wrangler.jsonc`。

```sh
npm run build
npx wrangler deploy
```

运行前需要登录具有目标账户和域名权限的 Cloudflare 账号。`routes` 只连接 `lottery.1eak.cool`。源码和依赖锁文件应一同提交，凭据不能提交到仓库。

GitHub Actions 负责构建与物理检查。Cloudflare 已连接该仓库的 main 分支，推送后运行 `npm test && npm run build` 并自动部署；已验证一次真实提交触发成功发布。预览分支部署关闭。验收范围和实际限制见 [DELIVERY.md](DELIVERY.md)。

## 物理模型的边界

依据制造商公开的双色球同类机械设备原理制作双逆向旋转混合和底部出球。搅拌部件形状、装球方式和通道是经过稳定性验证的简化模型，没有真实设备内部测量数据。该网站与中国福利彩票官方无关联，也没有使用官方视频或标志作为网站资产。

固定物理步长为 1/120 秒，物理在 Web Worker 中运行。低性能设备可能播放较慢，不能通过跳过物理步骤追赶时间。后台标签页暂停推进；返回后继续。回放要求相同模型版本和依赖锁定版本，不能将种子单独当作永久、跨所有版本的证明。

模拟结果不代表官方开奖，不用于预测。不承诺严格等概率；小规模稳定性测试也不是统计公平性认证。卡球、穿出边界或连续多球异常会终止场次并提示，不能用随机号码补齐。

## 新增福彩玩法（2026-10-01）

福彩 3D 的混合方式依据 AKANIS 气流原理；气流仍为经验场。官方同类气流设备采用顶部捕球，本版本复用了底部实体阀与接球通道，没有声称还原 Topaze 的真实捕球结构。七乐彩和快乐 8 依据 Ryo-Catteau 机械混合原理，内部转盘、尺寸和出球阀为开发尺度的简化模型，没有设备实测标定。

快乐 8 使用加长单行实体接球槽和低矮透明盖板，限制跳球、避免球在槽内越过其他球。盖板保留出口正下方入口。完成前所有球使用真实位置；完成后独立展示架显示两排十球，网页结果显示四排五球以适应手机。

新玩法通过 src/extended-physics.ts 接入同一物理 Worker。npm test 另外检查每种新玩法六个种子的完整开奖、数量、范围、去重或位置、特别号码、接球槽内顺序、完整物理状态回放；测试报告生成于本地 artifacts，不包含部署凭据。可以单独运行 npx tsx scripts/verify-extended.ts kl8。

参考：[中国福彩设备与球组采购（2026-07-07）](https://www.ccgp.gov.cn/cggg/zygg/cjgg/202607/t20260707_26887424.htm)、[AKANIS 气流设备](https://www.akanis.tech/)、[Ipomee](https://www.ryo-catteau.com/en/ipomee.htm)、[Stresa](https://www.ryo-catteau.com/en/stresa.htm)。

## 混合强度修订（2026-10-07）

大乐透与福彩 3D 使用 v3 气流：降低中央射流、旋流和扰动，仓顶附近平滑削弱上升风；风机用 1.2 秒渐进启动。12 组固定种子配对检查的平均动能为旧 v2 的 78.9%，同时检查上半仓覆盖、球色独立性与仓体边界。七乐彩和快乐 8 使用机械搅拌，转速独立从 8 降为 6 rad/s，模型升级机械 v2。双色球保持原模型与 8 rad/s 参数。旧模型历史号码保留，不用新参数误回放。


## 大乐透官方回放结构修订（2026-10-07）

当前模型 `dlt-airflow-v6` 根据用户提供的官方回放截图与四孔转盘说明修订：上下左右四孔，每次逆时针转 90°；顶部捕球，经左侧转到底部，沿固定弯道滚入单列接球架。前区收到 5 球、后区收到 2 球后立即关闭入口，转盘继续运行至孔内全部排空；前区球实际落稳后自动切后区，七球落稳后切接球架。

前区按号码使用蓝、黑、红、黄、绿五组球，后区白球，黄色两位数字印在曲面黑色方形底片上，06/09 下加横线。启动气流约十秒从弱渐强，强上升核心与外围回流共同混合球群。转盘通过运动学碰撞体承载动态号码球；没有按号码挑选赢家，也没有直接搬动球体位置。机身标签沿基座曲面贴合，球仓使用环境反射与透射材质。

转盘孔内承载、内部活动密封及尺寸仍是建模近似，气流为经验速度与阻力场，不能宣称设备完整复刻或风机实测标定。v5 将前区球误判为统一黑色、把转盘接送近似为滑移球兜，已替换。证据与限制见 [回放核对记录](docs/MACHINE_VIDEO_REVIEW.md)。
